## 〇、一句话结论

原意见书是一份**证据扎实、可信度高的问题清单**，但本质属于「专家走查发现集」，**不是数据驱动的需求优先级**。初版复核时两条结论需修正：① P0-1 因项目以桌面端 dmg 为主、且手机端占比未知而被暂置 Next；② P1-1 的 WCAG 违反程度因代码已带 `aria-label` 而被夸大。**后主上大人确认手机端占比 50%**，① 翻转：P0-1 确认为**最高优先级、立即修**（覆盖半数用户的核心功能在手机上失效）。P1-1 维持 S 级修正。其余条目方向正确，按产品节奏纳入即可。

**总体可信度：高（问题真实存在）；优先级校准：P0-1 上调为阻塞级（手机端 50%），P1-1 降级工时。**

## 二、决定 P0 的关键事实：发布通道 + 手机端占比

本项目**双发布通道**（来自工程惯例与 `package.json`）：

- **主通道：Tauri 桌面端**（`src-tauri/` 存在，`@tauri-apps/api`、`build:tauri` 已配，`release.yml` 编译 universal dmg）。桌面端是原生应用，用户用鼠标 → `onMouseUp` 正常 → **高亮 / 笔记 100% 可用**。
- **辅通道：网页版**（push main → GitHub Pages）。手机浏览器打开时才走触屏路径。

**手机端占比 50%（主上大人 2026-09-16 确认）**：手机无法运行 dmg，故这 50% 用户 100% 走网页版，且**全部受 P0-1 影响**——划词高亮/笔记在手机上完全不可用。

> ✅ **结论**：P0-1 覆盖半数用户的核心功能，属**发布阻塞级**。初版复核因占比未知暂置 Next，数据确认后**上调为最高优先级、立即修**。同时保留原判断：失效仅限手机网页版、桌面端不受影响。

## 四、可行性评估（技术现实与风险）

- **P0-1**：✅ 可做。⚠️ 真有坑：iOS Safari 选词松手会先弹系统「复制/共享」气泡，需确认是否拦截系统菜单，否则出现"系统菜单 + 应用浮层"双套；浮层坐标在触屏取得到（`getBoundingClientRect` 可用）。修复用 `handleTouchEnd` 有选区分支调 `openSelectionPopover()` 最直接。**真机回归（iOS/安卓）不可省**。覆盖 50% 用户，紧急但不能跳过验证。
- **P1-1**：✅ 极易。label 已存在，只需把 `c.label` 以文字/图案叠在 `.ann-color`（26px 圆点）上，或改圆点为"色块+文字"胶囊。零架构风险。
- **P1-2**：✅ 极简。给 `export-toast` / `restore-hint` / `bookmarkHint` 加 `role="status" aria-live="polite"`，对齐已有 `shelf-toast`。注意 toast 若 `setTimeout` 消失，`polite` 仍可播报。
- **P1-3**：✅ 标准 modal 补全。开时焦点锁在"取消/移除"间循环，关后回 × 按钮。可用现成 focus-trap 模式，无新增依赖必要。
- **P1-4**：✅ 可做。复用现有键位表做「?」速查浮层 + 首次轻引导（可"不再提示"）。低风险。
- **P2/P3**：✅ 均可做，但 **P2-1/2-2 属"假设需求"**，建议先用最轻量方式验证（如内测问卷 / 观察），避免为"我们认为好"的功能花 M 级工时。

## 五、剩余的产品缺口：缺用户数据

原意见书是"功能是否坏"视角，缺"谁在用、用多频繁"视角。本项目本地优先、零后端，**无埋点、无用户访谈**，除 P0-1 的手机占比（主上大人口述 50%）外：

1. **P2 增强的必要性无法证伪** → 可能做了一堆用户并不高频用的功能。
2. **其他条目 Impact/Reach 仍靠专家判断**。

**建议（并行于排期）**：
- 若要做数据驱动，可在网页版加**轻量匿名统计**（UV / 设备类型 / 高亮触发次数），纯本地不碰书内容，合规无忧；或发起 5–10 人内测走查。

1. **P0-1 排期（已定）**：手机端占比 50% → 确认为**最高优先级、立即修**；保留"失效仅限手机网页版、桌面端正常"的判断。
2. **P1-1 表述**：改为"读屏层已达标（`aria-label` 含语义词），未达标的是明眼色盲用户的视觉层；工时 M→S"。
3. **P3-5 数值**：对比度以目标主题背景重算（日间实测约 5.45:1，非 4.9），方向保留。
4. **补「非目标」段**：本轮聚焦"界面交互与无障碍合规"，**不扩张功能边界**（PDF、云同步、AI 笔记不在范围），防范围蔓延。
