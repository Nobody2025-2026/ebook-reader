# 字体功能验证清单

> 关联提交：`5b3c1c1` feat(typography): 精简为 5 种跨平台字体并支持自定义字体上传
> 维护方式：验证完一项就在对应格子打勾 ✅ 并填日期/结论；未验证留 ⬜。
> 创建于 2026-09-10，由主上大人要求建立，用于在有条件时逐步回填验证结果。

## 一、功能范围

- **内置字体**：宋体 / 黑体 / 楷体 / 圆体 / 仿宋（5 种，Mac + Windows 均原生支持）。
- **自定义字体**：通过阅读视图排版面板的「＋自定义」上传，用 FontFace API 注册，二进制存 IndexedDB，**跨平台一致**，应用启动自动重注册；当前选中字体可一键删除（删掉自动回落宋体）。
- **支持格式**（文件选择器 `accept` 白名单，见 `src/components/Reader.tsx:716`）：`.ttf`、`.otf`、`.woff`、`.woff2`。

## 三、通用通过标准

1. 选文件后面板立即出现该字体药丸（pill），正文排版**立刻**切换为该字体。
2. 刷新页面 / 重启应用后，字体仍在、正文仍生效（验证 IndexedDB 持久化 + 启动重注册）。
3. 在面板里点该字体药丸上的 × 删除后，正文回落宋体，控制台无报错。
4. 控制台无 `[customFont] 注册失败` 警告（见 `src/lib/customFont.ts`）。

## 四、验证步骤

### Mac（Web 版，最快）

```bash
node node_modules/vite/bin/vite.js --port 5180 --host 127.0.0.1
```

打开 http://127.0.0.1:5180 → 导入任意 EPUB → 打开阅读 → 排版面板「＋自定义」→ 选对应格式的字体文件 → 确认正文立即换字体 → 刷新确认仍在。

> 本项目禁用 `npm run` / `npx`（见项目 memory），统一用上面直连 node 的命令。

### Mac（Tauri 桌面版）

启动已构建的 `ebook-reader.app`（或本地 `tauri dev` / `tauri build` 产物），进入阅读视图重复上述「＋自定义」流程。

### Windows（Web 版，无需打包）

1. 在 Mac 上先产出静态产物：
   ```bash
   node node_modules/vite/bin/vite.js build   # 产物在 dist/
   ```
2. 把 `dist/` 拷到 Windows，用任意现代浏览器（Edge / Chrome）打开 `dist/index.html`。
3. 走「导入 EPUB → 阅读 → ＋自定义」流程，逐格式验证。

### Windows（Tauri 桌面版，需 Windows 机器 + Rust 工具链）

1. 在 Windows 上安装依赖后构建（本项目禁用 `npm run`，改用直连）：
   - Web 前端：`node node_modules/vite/bin/vite.js build`
   - 桌面壳：`node node_modules/@tauri-apps/cli/bin/tauri.js build`（或对应 Tauri v2 CLI 入口）
2. 安装生成的 `.msi` / `.exe`，进入阅读视图验证。
