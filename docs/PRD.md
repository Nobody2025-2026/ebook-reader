# 自制阅读器 · 产品设计文档

> 版本 v0.1（MVP 规划） · 2026-09-08

## 一、项目定位

**一句话目标：做一个能让人舒服地读完一本 EPUB 的阅读器。**

自己用的工具，不为发布、不为商业化。取舍时只问一件事：**这个功能是否直接服务于"把书读完"？是则留，否则延后。**

### 非目标（本轮明确不做）

PDF 阅读 · 账号与云同步 · 多设备 · TTS 朗读 · 字典翻译 · 笔记导出 · 书城与在线书源 · 移动端适配

> 说明：PDF 由既有的 PDF→EPUB 流水线负责转换成 EPUB 后导入，阅读器本身不背这个锅。

## 二、用户与场景

| 场景 | 期望 |
|---|---|
| 导入一批书 | 拖进去就能读，不用配置、不用注册 |
| 每天读一点 | 打开即回到上次位置，零操作成本 |
| 长时间阅读 | 字号行距主题可调，眼睛不累 |
| 读技术/学术书 | 目录随时跳转，方便回查章节 |

## 三、形态与技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 运行形态 | 纯 Web 应用 | 零后端，Mac / Windows 双机都能跑；日后可套 Tauri 转桌面端 |
| 框架 | Vite + React + TypeScript | 迭代快，类型安全 |
| EPUB 解析 | `epub.js` | 生态最全，CFI 定位成熟 |
| 存储 | IndexedDB | 存原始书文件 + 进度，容量够、无需后端 |
| 状态管理 | zustand | 轻量 |
| 排版 | CSS 变量 | 主题与排版参数实时切换 |
| 测试 | Vitest + 真实样本手工验收 | 见「七、验收标准」 |

**阅读模式：连续滚动**（不做分页翻页，规避窗口缩放重排的复杂度）。

## 四、功能范围

### P0 · MVP 必做

| # | 功能 | 要点 |
|---|---|---|
| 1 | 导入书籍 | 拖拽 / 文件选择；EPUB 为主，TXT 顺带 |
| 2 | 书库页 | 封面网格、书名作者、阅读百分比、"继续阅读"入口 |
| 3 | 阅读视图 | 正文渲染、图片内联、连续滚动 |
| 4 | 目录导航 | 侧边目录树，点击跳转章节 |
| 5 | 排版调节 | 字号、行距、页边距、衬线/无衬线；日间 / 护眼 / 夜间三主题 |
| 6 | 进度记忆 | EPUB CFI（TXT 用字符偏移），自动保存，重开回到原处 |
| 7 | 键盘操作 | ← → 滚动、空格翻屏、Esc 回书库 |

### P1 · MVP 之后

高亮与笔记 · 书签 · 全文搜索 · 阅读时长统计

### P2 · 已砍出本轮

账号 / 云同步 · PDF · TTS · 字典翻译 · 导出分享

## 五、页面结构

| 页面 | 职责 |
|---|---|
| 书库页 `/` | 展示全部书籍、导入入口、继续阅读、删除书籍 |
| 阅读页 `/read/:id` | 正文、目录抽屉、顶部工具条（返回 / 目录 / 排版 / 进度） |
| 排版面板 | 浮层，实时预览字号、行距、页边距、字体、主题 |

## 六、数据模型（IndexedDB）

```ts
Book       { id, title, author, cover?, format: 'epub'|'txt', file: Blob, addedAt }
Progress   { bookId, cfi: string, percent: number, chapterTitle, updatedAt }
Settings   { fontSize, lineHeight, pageMargin, fontFamily, theme }   // 全局单条
```

三个 object store：`books` / `progress` / `settings`。设置全局共用，不按书区分（MVP 阶段够用）。

## 七、验收标准（MVP 完成定义）

功能验收：

- [ ] 拖入标准 EPUB，3 秒内渲染出正文
- [ ] 连续滚动流畅，图片正常显示，无白屏闪烁
- [ ] 调整字号 / 行距 / 主题即时生效，且不丢失阅读位置
- [ ] 刷新页面自动回到上次位置，误差不超过一屏
- [ ] 目录点击跳转准确
- [ ] 键盘 ← → 滚动、Esc 返回书库
- [ ] 删除书籍连带清理进度记录

工程验收（依 `AGENTS.md`）：

- [ ] Vitest 单测覆盖 EPUB 解析层与进度读写，全绿
- [ ] 三本真实 EPUB 手工验收通过，其中必须含《涛动周期论》OCR 版（脏目录 / 乱标签 / 缺封面）
- [ ] 每个功能点独立 commit，可单独回滚

## 八、里程碑

| 阶段 | 内容 |
|---|---|
| M1 | 脚手架 + EPUB 解析 + 正文渲染（跑通最小闭环） |
| M2 | 书库页 + IndexedDB 存储 + 进度记忆 |
| M3 | 排版面板 + 主题 + 目录跳转 + 键盘操作 |
| M4 | 验收打磨：空状态、错误处理、大书性能 |

## 九、待决问题

- 超过 10MB 的大部头加载性能是否需要预解析 / 懒加载
- 封面缺失时的占位方案
- 滚动位置精度：按 CFI 还是按滚动像素（MVP 先走 CFI）
- TXT 无目录结构，目录区如何处理（MVP 先隐藏）
